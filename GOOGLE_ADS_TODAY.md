# 🚀 Google Ads — Setup em 30 Minutos (Hoje)

**Tempo**: 30 minutos  
**Resultado**: 500-2000 cliques/dia  
**Timeline**: Deploy hoje → Ads rodam amanhã

---

## Passo 1: Ir para Google Ads (2 min)

👉 https://ads.google.com

### 1.1 Login
- Use sua conta Google (gmail)
- Se não tiver conta, crie uma

### 1.2 Criar Nova Conta
- Click "Start now"
- Business name: "ENEM Pro"
- Country: Brasil
- Timezone: São Paulo
- Click "Continue"

---

## Passo 2: Configurar Primeira Campanha (10 min)

### 2.1 Tipo de Campanha
- Escolha: **Search Campaigns** (buscar usuários)
- Click "Continue"

### 2.2 Objetivo
- Escolha: **Website traffic** (trazer tráfego)
- Click "Continue"

### 2.3 Configuração da Campanha

**Campaign name:**
```
ENEM Pro - Questões (Teste)
```

**Campaign type:** Search

**Networks:**
- ✅ Google Search
- ✅ Search partners
- ❌ Google Display Network (desmarcar)

**Budget:**
```
Daily Budget: R$ 100
(Você pode aumentar depois)
```

**Click "Create campaign"**

---

### 3.1 Ad Group Name
```

## Passo 4: Criar Anúncio (8 min)

```

### 4.4 Display URL
```
questoesenem.pro
```

## Passo 5: Lances de Oferta (0 min - Automático)

Deixe como padrão:
- **Bid strategy:** Maximize clicks

## Passo 6: Revisar e Publicar (5 min)

1. Review tudo
2. Click "Publish campaign"
3. Confirmar payment method
4. ✅ Pronto!

## 🎯 Otimizações (Semana que vem)

Após 1 semana:
1. Aumentar budget para R$ 200-300/dia (se ROI bom)
2. Adicionar mais keywords específicas
3. Testar diferentes headlines
4. Criar campanha separada para brand (questoesenem)
5. Adicionar Smart Bidding

---

## 💡 Dicas Extras

- Não gaste R$ 100 no primeiro dia → comece com R$ 50
- Espere 24h antes de otimizar (Google precisa de dados)
- Se CTR < 1%, reescreva headlines
- Se conversão < 0.5%, melhore landing page
