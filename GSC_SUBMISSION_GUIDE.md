**Objetivo**: Acelerar indexação dos 64+ posts + ferramentas

---

## ✅ PASSO-A-PASSO (5 MINUTOS)

### 1. Abrir Google Search Console
```
https://search.google.com/search-console
```

### 2. Selecionar propriedade
```
questoesenem.pro
```

### 3. Menu esquerdo → "Sitemaps"

### 4. Clicar "NOVO SITEMAP"

### 5. Colar URL
```
https://questoesenem.pro/sitemap.xml
```

### 6. Clicar "Enviar"

---

## 📊 O QUE MONITORAR

### Coverage (Cobertura)
- **Valid** = URLs indexadas ✅
- **Excluded** = Posts com noindex (normal)
- **Error** = URLs com problema (investigar)

### Request Indexing (Indexação Manual)
Para acelerar ainda mais:
1. Voltar a "Sitemaps"
2. Clicar no sitemap enviado
3. "Request indexing" nos top 50 URLs
