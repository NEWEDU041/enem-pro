# Equações de 1º e 2º Grau no ENEM: Fórmulas, Técnicas e Exemplos Resolvidos

## Introdução
Equações do primeiro e segundo grau aparecem com frequência nas questões de Matemática do ENEM. Este post mostra passo a passo como dominar.

## Key Takeaways
- Primeiro grau: ax + b = 0, isolando x: x = -b/a
- Segundo grau: Δ = b² - 4ac, depois Bhaskara: x = (-b ± √Δ) / 2a

## Como resolver equações do primeiro grau rapidamente?

Equação primeiro grau: ax + b = c. Isolam x: x = (c - b) / a. Exemplo: 3x + 5 = 14. Passa o 5: 3x = 9. Divide por 3: x = 3. Isto leva 30 segundos. Armadilha: candidatos muitas vezes invertam sinais. Ao passar número para outro lado, mude sinal: +5 vira -5, ×3 vira ÷3.

Verificação: substitua x = 3 na equação original. 3(3) + 5 = 14? Sim: 14 = 14. Correta.

## Qual é a fórmula de Bhaskara e como aplicá-la sem erros?

Bhaskara resolve ax² + bx + c = 0. Primeiro: calcule Δ = b² - 4ac. Depois: x = (-b ± √Δ) / 2a. Exemplo: x² - 5x + 6 = 0. a=1, b=-5, c=6. Δ = (-5)² - 4(1)(6) = 25 - 24 = 1. x = (5 ± 1) / 2. x' = 3, x'' = 2. Verificação: (3)² - 5(3) + 6 = 9 - 15 + 6 = 0. Correta.

Erro comum: esquecer que b = -5, então -b = 5 (não -5).

## Quando devo usar fatoração e quando devo usar Bhaskara?

Se a equação fatora facilmente, fatore. Exemplo: x² - 5x + 6 = (x-2)(x-3) = 0, então x = 2 ou x = 3. Isto é mais rápido que Bhaskara (tempo: 1 minuto vs 2 minutos). Se não fatora facilmente ou Δ não é quadrado perfeito, use Bhaskara. Conhecer isto economiza um tempo valioso ao longo da prova, já que evita aplicar Bhaskara quando a fatoração resolveria mais rápido.

## Como interpretar o discriminante (delta) e o número de soluções?

Δ > 0: duas soluções reais e distintas. Δ = 0: uma solução real (raiz dupla). Δ < 0: nenhuma solução real (raízes complexas). O ENEM pede frequentemente "quantas soluções" ou "qual é a natureza das raízes". Δ decide tudo. Técnica: antes de calcular raízes, calcule Δ e já saiba se há solução. Isto acelera a resposta em 30 segundos por questão.

## Tabela Comparativa: Resolução de Equações

| Tipo | Forma Padrão | Método Rápido | Quando Usar | Tempo |
|---|---|---|---|---|
| **1º Grau** | ax + b = 0 | Isola x: x = -b/a | Sempre aplicável | 30 seg |
| **2º Grau (Fatorável)** | ax² + bx + c = 0 | Fator: (x-r₁)(x-r₂)=0 | Se identifica fatores rápido | 1 min |
| **2º Grau (Bhaskara)** | ax² + bx + c = 0 | Δ = b²-4ac, x = (-b±√Δ)/2a | Se não fatora ou Δ complexo | 2-3 min |
| **Incompleta (b=0)** | ax² + c = 0 | x² = -c/a, x = ±√(-c/a) | Quando b falta | 30 seg |
| **Incompleta (c=0)** | ax² + bx = 0 | x(ax+b) = 0, x=0 ou x=-b/a | Quando c falta | 30 seg |
| **Com Frações** | (ax+b)/d = c | Multiplica por denominador comum | Elimina denominadores primeiro | 1-2 min |

**Regra do Discriminante:** Calcule Δ PRIMEIRO para saber se há solução real antes de gastar tempo com cálculos.

## Exemplos Práticos: Equações Resolvidas

### Exemplo 1: Equação de 1º Grau Simples
Resolva: 3x - 7 = 2

**Solução:**
- 3x = 2 + 7
- 3x = 9
- x = 9/3 = 3
- **Verificação:** 3(3) - 7 = 9 - 7 = 2 ✓
- **Resposta: x = 3**

### Exemplo 2: Equação de 2º Grau com Fatoração (Rápida)
Resolva: x² - 5x + 6 = 0

**Solução (Fatoração):**
- Procura dois números que multiplicam para 6 e somam para -5: -2 e -3
- Fatora: (x - 2)(x - 3) = 0
- Soluções: x = 2 ou x = 3
- **Resposta: x = 2 ou x = 3** (em ~1 minuto)

### Exemplo 3: Equação de 2º Grau com Bhaskara (Complexa)
Resolva: 2x² + 3x - 5 = 0

**Solução (Bhaskara):**
- a = 2, b = 3, c = -5
- Δ = 3² - 4(2)(-5) = 9 + 40 = 49
- x = (-3 ± √49) / (2×2) = (-3 ± 7) / 4
- x₁ = (-3 + 7)/4 = 4/4 = 1
- x₂ = (-3 - 7)/4 = -10/4 = -2,5
- **Resposta: x = 1 ou x = -2,5**

### Exemplo 4: Equação Incompleta (Falta b)
Resolva: x² - 16 = 0

**Solução:**
- x² = 16
- x = ± 4
- **Resposta: x = 4 ou x = -4**
- (Bhaskara também funciona, mas este método é mais rápido)

### Exemplo 5: Equação com Frações
Resolva: x/2 + 3 = 5

**Solução:**
- Multiplica tudo por 2: x + 6 = 10
- x = 4
- **Resposta: x = 4**

### Exemplo 6: Aplicação Prática (ENEM-Style)
Um retângulo tem comprimento 3 metros maior que a largura. Se a área é 40 m², qual é a largura?

**Solução:**
- Largura = x, comprimento = x + 3
- Área = x(x+3) = 40
- x² + 3x - 40 = 0
- Δ = 9 + 160 = 169
- x = (-3 ± 13)/2 = 5 ou -8
- Como largura não é negativa, x = 5 metros
- **Resposta: Largura = 5 metros**

## Armadilhas Comuns e Troubleshooting

### Erro 1: Trocar Sinais ao Isolar x
**Armadilha:** "3x - 7 = 2, então 3x = 2 - 7 = -5?"
**Correto:** Passa -7 para o outro lado: 3x = 2 + 7 = 9. Sinal muda.

### Erro 2: Esquecer que -b, não b, na Fórmula de Bhaskara
**Armadilha:** "x² - 5x + 6 = 0, Bhaskara: x = (5 ± √...)?" (Estava certo)
**Correto:** Se a forma é x² - 5x + 6, então b = -5, então -b = 5. A fórmula diz x = (-b ± √Δ) / 2a = (5 ± √Δ) / 2. Preste atenção no sinal de b.

### Erro 3: Calcular Δ Incorretamente
**Armadilha:** "2x² - 3x + 1 = 0: Δ = (-3)² - 4(2)(1) = 9 - 8... espera, qual é b?"
**Correto:** Δ = b² - 4ac. Aqui, a=2, b=-3, c=1. Δ = (-3)² - 4(2)(1) = 9 - 8 = 1. Não confunda coeficientes.

### Erro 4: Divisão Errada em Bhaskara
**Armadilha:** "x = (-b ± √Δ) / a?" (dividir só por a, não 2a)
**Correto:** x = (-b ± √Δ) / 2a. Divide por 2a, não a. O "2" é crítico.

### Erro 5: Não Verificar Soluções em Problemas Contextuais
**Armadilha:** "Área = 40, x² + 3x - 40 = 0 dá x = 5 ou x = -8. Resposta: -8 metros"
**Correto:** Em contexto, descartar soluções negativas (não há comprimento negativo). Resposta é x = 5.

### Erro 6: Aplicar Bhaskara quando Fatoração é Mais Rápida
**Armadilha:** "x² - 7x + 10 = 0: calcular Δ = 49-40 = 9, depois x = (7±3)/2..."
**Correto:** Reconheça que (x-2)(x-5) = 0 é mais rápido (30 seg vs 2-3 min). Prátique reconhecer fatores.

## FAQ Expandido

**P: Como verificar se a resposta está correta sem usar calculadora?**
R: Substitua x na equação original. Para 1º grau: ax + b deve igual c. Para 2º grau: ax² + bx + c deve igual 0. Se conseguir fazer isto mentalmente, economiza tempo e reduz erros em 50%.

**P: O ENEM cobra equações com frações ou decimais?**
R: Sim, frações aparecem em 2-3 questões. Se há fração, multiplique toda equação pelo denominador comum PRIMEIRO. Exemplo: (x/2) + 3 = 5 → multiplica por 2 → x + 6 = 10 → x = 4. Isto elimina frações e simplifica. Decimais são raros (0-1 questão por prova); se aparecem, converta para fração.

**P: Equações paramétricas (com incógnita em outro lugar) caem no ENEM?**
R: Raramente como questão direta ("resolva em x"). Aparecem em problemas de aplicação ("qual x torna isto verdadeiro?", "para que valor de x a área é máxima?"). Nesse caso, monte a equação a partir do enunciado, depois resolva normalmente.

**P: O que fazer se Δ é negativo?**
R: Isto significa não há solução real. Se o enunciado pede "quantas soluções", resposta é zero. Se pede "resolvendo nos complexos", as soluções envolvem i (unidade imaginária), mas isto é raro no ENEM.

**P: Como reconhecer rapidamente se uma quadrática fatora?**
R: Procure dois números que multiplicam para c e somam para b. Se encontra rapidamente, fatore. Se não encontra em 10 segundos, use Bhaskara. Pratica com 5-10 exercícios, e isto vira automático.

**P: Qual é a diferença entre "raízes" e "soluções"?**
R: Na verdade, "raízes" e "soluções" geralmente significam a mesma coisa em equações. Raízes é mais comum em polinômios; soluções em equações em geral. Ambas significam valores de x que tornam a equação verdadeira.

## Dicas de Estudo e Checklist

### Checklist Antes da Prova
- [ ] Decorar fórmula de Bhaskara: x = (-b ± √Δ) / 2a
- [ ] Entender a regra do discriminante: Δ = b² - 4ac
- [ ] Fazer 10-15 equações de 1º grau até resolver em 30 segundos
- [ ] Fazer 15-20 equações de 2º grau: metade por fatoração, metade por Bhaskara
- [ ] Praticar equações com frações (eliminar denominadores primeiro)
- [ ] Resolver 3-5 problemas contextuais (área, perímetro, etc.)

### Estratégia de Resolução (Passo a Passo)
1. **Identifique o tipo:** 1º grau ou 2º grau?
2. **Simplifique:** Elimine frações, distribua, combine termos semelhantes
3. **Padrão:** Coloque na forma padrão (ax+b=0 ou ax²+bx+c=0)
4. **Escolha método:** 1º grau = isola. 2º grau = tenta fatoração, senão Bhaskara
5. **Resolva:** Aplique a técnica
6. **Verifique:** Substitua na original ou verifique no contexto

### Tempo de Estudo Recomendado
- **Iniciantes:** 3-4 horas (1º grau + 2º grau básico + 25 exercícios simples)
- **Intermediários:** 2-2.5 horas (fatoração vs. Bhaskara + 18 exercícios variados incluindo frações)
- **Avançados:** 45-60 minutos (revisão rápida + 10-15 exercícios complexos com aplicações contextuais)
