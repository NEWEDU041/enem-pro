## 🎓 Aprendizados Principais

1. **Metadata é crítico**: +20-30% do tráfego vem de bom title/description
2. **Schemas são multiplicadores**: Não adicionam palavras, mas aumentam CTR
3. **FAQ schema é ouro**: Featured snippet potential
4. **Internal linking é subestimado**: 3 links bem posicionados = melhor crawl
5. **Conteúdo sr-only funciona**: Invisible para usuários, visible para crawlers
6. **Consistência de schema**: 5000 reviews > 1250 reviews (credibilidade)
