## Regenerating Reports

Run individual analysis scripts:

```bash
# Regenerate cohort analysis
python3 scripts/cohort_analysis.py

# Regenerate retention curves
python3 scripts/retention_analysis.py

# Regenerate churn predictions
python3 scripts/churn_prediction.py

# Regenerate revenue forecast
python3 scripts/revenue_forecast.py

# Run all tests
python3 scripts/analytics_simulation.py
```

Reports are saved to `scripts/` directory and can be copied to `reports/` for archival.

## Data Sources

All reports are generated from Supabase tables:
- `premium_subscribers` - User signup data
- `product_downloads` - User activity tracking
- `trial_offers` - Trial conversion data
- `product_analytics` - Event tracking

With materialized views:
- `v_cohort_retention_matrix` - Cohort analysis data
- `v_churn_risk_summary` - Churn aggregates
- `v_weekly_cohort_growth` - Growth trends
