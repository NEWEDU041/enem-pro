# Google Search Console API — Guia Completo 2026

**Setup, Performance Queries & Troubleshooting**

## 🎯 QUICK START (5 MINUTOS)

```python
# 1. Install
pip install google-auth-oauthlib google-api-python-client

# 2. Authenticate
from google.oauth2.service_account import Credentials
creds = Credentials.from_service_account_file('client_secret.json')

# 3. Build service
from googleapiclient.discovery import build
service = build('webmasters', 'v3', credentials=creds)

# 4. Query GSC data
request = service.searchanalytics().query(
    siteUrl='https://example.com/',
    body={'startDate': '2026-10-01', 'endDate': '2026-11-01'}
)
response = request.execute()
print(response)
```

**Result:** ✅ GSC data retrieved!

## 🛠️ TROUBLESHOOTING

### 403 Forbidden (No Verified Property)

```
Cause: Site not verified in Search Console
Solution:
1. Go to https://search.google.com/search-console
2. Add property https://enem-pro.com/
3. Verify ownership (DNS, HTML file, or Google Analytics)
4. Re-authorize OAuth
```

### Empty Results

```
Cause: No data yet (site too new or no queries)
Solution:
1. Check Search Console dashboard
2. Wait 2-3 days for dataState='final'
3. Verify site has at least 1 page indexed
```
