# Estatística no ENEM: Como Calcular Média, Mediana, Moda e Interpretar Dados

## Introdução
Estatística aparece com frequência nas questões de Matemática no ENEM. Muitos candidatos memorizam definições mas erram aplicação. Este post mostra quando usar cada uma.

## Key Takeaways
- Média: soma dividida pela quantidade (x̄ = Σx / n)
- Mediana: valor central quando dados ordenados; Moda: valor mais frequente

## Como calcular média e quando é a resposta correta no ENEM?

Média é soma de todos valores dividida pela quantidade. Fórmula: x̄ = (x₁ + x₂ +... + xₙ) / n. Exemplo: notas 70, 80, 90. Média = (70 + 80 + 90) / 3 = 240 / 3 = 80. O ENEM pede média quando quer "valor típico" ou "desempenho geral". Armadilha: média é sensível a valores extremos.

Detalhe importante: média ponderada (cada valor tem peso diferente). Fórmula: x̄ = Σ(xᵢ × wᵢ) / Σwᵢ. Exemplo: prova 1 (peso 1): 70; prova 2 (peso 2): 80. Média ponderada = (70×1 + 80×2) / (1+2) = 230/3 ≈ 76,7 (não 75). Este detalhe aparece em

## Qual é a diferença entre média, mediana e moda em um conjunto de dados?

Média: valor central por cálculo. Mediana: valor central por posição (quando dados ordenados). Moda: valor que aparece mais vezes. Exemplo: dados {1, 2, 2, 3, 3, 3, 100}. Média = 114/7 ≈ 16,3 (influenciada pelo 100 extremo). Mediana = 3 (valor central é 3). Moda = 3 (aparece 3 vezes). Quando usar qual? Distribuição normal: use média. Distribuição com valores extremos: use mediana.

Dados categóricos: use moda. Moda aparece raramente isolada.

## Como encontrar a mediana rapidamente em um conjunto de dados?

Ordene dados. Se quantidade é ímpar, mediana é o valor central. Exemplo: {2, 5, 8, 9, 15} tem 5 elementos. Mediana = 8 (3º elemento). Se quantidade é par, mediana é a média dos dois valores centrais. Exemplo: {2, 5, 8, 9} tem 4 elementos. Mediana = (5 + 8) / 2 = 6,5 (média dos 2º e 3º). Tempo: 1-2 minutos incluindo ordenação. Muitos candidatos gastam bem mais tempo aqui por falta de método claro. Uma estrutura clara para ordenar e contar os elementos economiza tempo significativo na prova.

## O que é desvio padrão e quando aparece em questões do ENEM?

Desvio padrão mede dispersão dos dados. Se valores estão próximos da média, desvio padrão é pequeno. Se dispersos, desvio grande. Fórmula é complexa, mas conceito é simples. No ENEM, desvio padrão raramente pede cálculo completo (apenas em 1-2 questões). Pede interpretação: "qual distribuição tem maior dispersão?". Distribuição A com desvio 5 é mais concentrada que distribuição B com desvio 10.

## Tabela Comparativa: Medidas de Tendência Central

| Medida | Fórmula | Quando Usar | Sensível a Valores Extremos? | Exemplo |
|---|---|---|---|---|
| **Média (x̄)** | Σx / n | Dados normais, distribuição simétrica | Sim, muito | Notas: 70, 80, 90 → Média = 80 |
| **Média Ponderada** | Σ(x × w) / Σw | Valores têm pesos diferentes | Sim, muito | Provas: 70(peso 1) + 80(peso 2) = 76,7 |
| **Mediana** | Valor central (dados ordenados) | Distribuição assimétrica, dados extremos | Não | {1, 2, 100}: Mediana = 2 (não influenciada por 100) |
| **Moda** | Valor mais frequente | Dados categóricos, distribuições discretas | Não | Cores: azul, azul, vermelho, vermelho, verde → Moda = ambas |
| **Desvio Padrão (σ)** | √(Σ(x - x̄)² / n) | Medir dispersão dos dados | Sim, extremamente | Se σ pequeno, dados concentrados |

**Dica de Prova:** Dados com valores muito diferentes? Use mediana. Dados normais? Use média. Dados categóricos? Use moda. Comparar dispersão? Use desvio padrão (ou apenas compare visualmente).

## Exemplos Práticos: Cálculos e Interpretações

### Exemplo 1: Calcular Média Simples
Notas de um aluno: 60, 70, 80, 90. Qual é a média?

**Solução:**
- x̄ = (60 + 70 + 80 + 90) / 4 = 300 / 4 = 75
- **Resposta: Média = 75**

### Exemplo 2: Média Ponderada (Provas com Pesos)
Aluno: Prova 1 (peso 1): 70; Prova 2 (peso 2): 85; Prova 3 (peso 3): 90. Qual é a média ponderada?

**Solução:**
- Soma ponderada = 70×1 + 85×2 + 90×3 = 70 + 170 + 270 = 510
- Soma pesos = 1 + 2 + 3 = 6
- x̄ = 510 / 6 = 85
- **Resposta: Média ponderada = 85**

### Exemplo 3: Encontrar Mediana em Conjunto Ímpar
Dados: {3, 1, 4, 1, 5, 9, 2}. Qual é a mediana?

**Solução:**
- Ordena: {1, 1, 2, 3, 4, 5, 9}
- Quantidade = 7 (ímpar)
- Mediana = valor central = 4º elemento = 3
- **Resposta: Mediana = 3**

### Exemplo 4: Encontrar Mediana em Conjunto Par
Dados: {10, 20, 30, 40}. Qual é a mediana?

**Solução:**
- Já está ordenado
- Quantidade = 4 (par)
- Mediana = média dos 2º e 3º elementos = (20 + 30) / 2 = 25
- **Resposta: Mediana = 25**

### Exemplo 5: Interpretar Dispersão com Desvio Padrão
Turma A: notas {70, 75, 80, 85, 90}, desvio padrão = 7,9
Turma B: notas {60, 65, 70, 80, 95}, desvio padrão = 13,2

Qual turma teve desempenho mais consistente?

**Solução:**
- Turma A tem desvio padrão menor (7,9 < 13,2)
- Desvio menor = dados mais concentrados (consistentes)
- **Resposta: Turma A teve desempenho mais consistente**

### Exemplo 6: Comparar Média vs. Mediana (Valor Extremo)
Dados: {1, 2, 3, 4, 100}. Qual medida representa melhor o "típico"?

**Solução:**
- Média = (1 + 2 + 3 + 4 + 100) / 5 = 110 / 5 = 22 (influenciada por 100)
- Mediana = 3 (valor central, não afetado por 100)
- Mediana (3) representa melhor porque ignora extremo
- **Resposta: Mediana é mais representativa quando há outlier**

## Armadilhas Comuns e Troubleshooting

### Erro 1: Confundir Média com Mediana
**Armadilha:** "Dados {1, 2, 100}: média e mediana são a mesma coisa?"
**Correto:** Média = 34,3 (afetada por 100). Mediana = 2 (não afetada). São diferentes quando há extremos.

### Erro 2: Esquecer de Ordenar Dados para Mediana
**Armadilha:** "Dados {5, 1, 3}: mediana = 1 (primeiro valor)?"
**Correto:** Ordena primeiro: {1, 3, 5}. Mediana = 3 (valor central). Ordem importa.

### Erro 3: Calcular Mediana Errada em Conjunto Par
**Armadilha:** "Dados {2, 4, 6, 8}: mediana = 4 (2º elemento)?"
**Correto:** Mediana de conjunto par = média dos dois centrais = (4+6)/2 = 5. Não é só o 2º.

### Erro 4: Não Aplicar Pesos na Média Ponderada
**Armadilha:** "Notas 80, 90, 100 com pesos 1, 2, 3: média = (80+90+100)/3 = 90?"
**Correto:** Com pesos: (80×1 + 90×2 + 100×3)/(1+2+3) = 470/6 ≈ 78,3. Pesos mudam resultado.

### Erro 5: Entender Errado o Desvio Padrão
**Armadilha:** "Desvio padrão maior = dados melhores?"
**Correto:** Desvio padrão maior = dados mais DISPERSOS (menos consistentes). Não é necessariamente ruim; depende do contexto.

### Erro 6: Moda em Dados Sem Repetição
**Armadilha:** "Dados {1, 2, 3, 4}: qual é a moda?"
**Correto:** Se nenhum valor se repete, não há moda (ou todos são moda). Moda é para dados com repetição.

## FAQ Expandido

**P: O ENEM usa fórmula de desvio padrão que precisa memorizar?**
R: Não. As fórmulas de desvio padrão no ENEM são DADAS quando precisas. Foco está em conceito: "qual distribuição tem maior dispersão?" Isto reduz pressão de memorização e permite responder sem fazer cálculos complexos.

**P: Como organizar dados quando há tabelas grandes?**
R: Use papel rascunho. (1) Copie valores em coluna. (2) Ordene colocando menores no topo. (3) Marque posição central com caneta. (4) Leia quantidade (n) rapidamente. (5) Localize mediana dividindo n por 2. Estrutura = velocidade.

**P: Média, mediana, moda podem ser iguais?**
R: Sim, em distribuição perfeitamente simétrica (ex: {1, 2, 3, 2, 1}): Média = 2,2, Mediana = 2, Moda = 2 (todos próximos). Mas é raro. Quando aparecem iguais, questão geralmente explora entendimento de simetria.

**P: Qual é a diferença entre amostra e população em estatística?**
R: População = todos os dados (ex: todas as notas de uma escola). Amostra = parte dos dados (ex: 30 alunos de uma escola de 1000). ENEM usa ambas. Para população, usa σ. Para amostra, usa s (com n-1 em vez de n no denominador). Diferença é técnica, mas importante em cálculos.

**P: O ENEM cobra intervalo de confiança ou margens de erro?**
R: Raramente. Intervalo de confiança é tópico avançado (estatística inferencial). ENEM foca em estatística descritiva (média, mediana, moda, distribuição visual). Se cai intervalo, questão diz "entre 50% e 70%" e pede interpretação, não cálculo.

**P: Como interpretar gráficos estatísticos (histograma, boxplot, dispersão)?**
R: Histograma: frequência por intervalo (altura = frequência). Boxplot: mostra mediana, quartis, outliers visualmente. Gráfico dispersão: relação entre 2 variáveis (correlação). ENEM pede leitura visual: "qual intervalo tem mais dados?" "Qual ponto é outlier?" Não pede cálculo.

### Estratégia de Resolução (Passo a Passo)
1. **Identifique:** Qual medida é pedida (média, mediana, moda, desvio)?
2. **Organize:** Ordene dados (especialmente para mediana)
3. **Calcule:** Aplique fórmula apropriada
4. **Interprete:** Resultado faz sentido? Compare com outras medidas?
5. **Verifique:** Se há tabela/gráfico, confirme leitura visual
