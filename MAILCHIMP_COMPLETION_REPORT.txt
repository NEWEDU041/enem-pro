CONFIGURATION REQUIRED
================================================================================

MAILCHIMP SETUP
  1. Create OAuth Application
     - Get Client ID & Client Secret
     - Set Redirect URI
  
  2. Set up Audience
     - Get Audience ID
     - Note API Server (us1, us2, etc)
  
  3. Configure Webhook
     - URL: https://enempro.com.br/api/webhooks/mailchimp
     - Events: subscribe, unsubscribe, campaign
     - Get Webhook Secret

ENVIRONMENT VARIABLES (.env.local)
  MAILCHIMP_CLIENT_ID=...
  MAILCHIMP_CLIENT_SECRET=...
  MAILCHIMP_REDIRECT_URI=...
  MAILCHIMP_API_KEY=...
  MAILCHIMP_SERVER=us1
  MAILCHIMP_AUDIENCE_ID=...
  MAILCHIMP_WEBHOOK_SECRET=...

================================================================================
INTEGRATION POINTS
================================================================================

ON USER SIGNUP
  1. Add to Mailchimp audience
  2. Assign to "new" cohort segment
  3. Start onboarding campaign (Day 0)
  4. Calculate churn risk score

ON USER ACTIVITY
  1. Update behavior segment
  2. Tag with engagement level
  3. Route to nurture or re-engagement
  4. Recalculate churn risk

ON CHURN DETECTION
  1. ML score > 0.6
  2. Send churn-risk campaign (Day 0)
  3. Monitor engagement
  4. Escalate offer if no response

ON TRIAL EXPIRY
  1. Detect expiration date approaching
  2. Send upgrade campaign
  3. Monitor conversion
  4. Update LTV prediction
