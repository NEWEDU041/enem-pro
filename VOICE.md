# ENEM Pro — Voice & Style Guide

## Voz
**Direto. Confiável. Sem enrolação.**

O leitor do ENEM Pro é um estudante com tempo escasso. Cada parágrafo deve entregar valor imediato.

## Pronome e perspectiva
- Segunda pessoa do singular: "você", "seu", "sua"
- Nunca primeira pessoa do plural ("nós, a equipe do ENEM Pro")
- Voz ativa predominante

## Comprimento de sentença
- Máximo 25 palavras por sentença
- Parágrafos: 50–120 palavras
- Nunca parágrafos com mais de 3 frases consecutivas sem quebra visual (lista, tabela ou subtítulo)

## Headings
- H1: título SEO, máximo 65 caracteres
- H2: cada seção principal, formato pergunta ou "O que cai" / "Como [ação]"
- H3: subtópicos dentro de seções, ex: disciplinas, anos, etapas
- Nunca pule nível (H1 → H2 → H3 sem H4)

## Dados e fontes
- Todo número precisa de fonte ou contexto ("segundo o INEP", "nos últimos 10 anos", "de 2009 a 2024")
- Preferir dados do INEP, IBGE, MEC
- Nunca fabricar estatísticas
- Tabelas para comparação de dados (notas de corte, distribuição de questões)

## Estrutura padrão de artigo
1. **Abertura direta:** responde a pergunta principal nos primeiros 60 palavras
2. **Desenvolvimento em H2s:** cada seção autocontida (funciona isolada)
3. **Tabelas/listas** para dados densos
4. **Dica em negrito** ao final de seções técnicas
5. **Separador horizontal `---`** antes do CTA final
6. **CTA final:** 2–3 linhas, link implícito ao ENEM Pro (sem URL literal no texto)

## Anti-padrões — NUNCA usar
- "É muito importante que você saiba..." → começa já com o que é importante
- "Neste artigo, vamos ver..." → vai direto ao assunto
- "Como todos sabem..." → não todos sabem, por isso estão lendo
- Adjetivos vazios: "incrível", "revolucionário", "fantástico"
- "Clique aqui" → use texto âncora descritivo
- Múltiplos pontos de exclamação consecutivos
- Frases com "definitivamente", "literalmente" (a menos que necessário para ênfase real)

## Termos padronizados
| Usar | Evitar |
|------|--------|
| ENEM | Enem, enem |
| INEP | Inep |
| TRI | tri |
| SISU | Sisu |
| questão | exercício, problema |
| disciplina | matéria (OK informalmente) |
| candidato | aluno (no contexto do ENEM) |

## Exemplo de abertura ✅ (certo)
"Passar no ENEM não é sobre estudar mais — é sobre estudar o que cai, do jeito que o ENEM pergunta."

## Exemplo de abertura ❌ (errado)
"Neste artigo completo e definitivo, vamos explorar juntos todas as estratégias incríveis que você precisa saber para se preparar para o ENEM 2026!"

## FAQ schema
Todo artigo deve ter pelo menos 3 perguntas em FAQ no final (para schema FAQPage):
- Formato: H3 com "?" no final
- Resposta: 40–80 palavras
- Perguntas baseadas em variações reais da keyword principal
