# Enterprise Security Middleware Stack\n\n## Overview\n\nA comprehensive, production-ready security middleware stack for Next.js/Express applications. Provides:\n\n✅ **Rate Limiting** — 5-10 req/min per IP (configurable)  \n✅ **CORS** — Origin whitelist (no `*` in production)  \n✅ **CSRF Protection** — Token-based with double-submit cookie pattern  \n✅ **Input Validation** — XSS prevention, malicious pattern detection  \n✅ **Security Headers** — CSP, X-Frame-Options, HSTS, and more  \n\n---\n\n## Architecture\n\n```\nRequest → Rate Limit → CORS → CSRF → Input Validation → Security Headers → Handler\n```\n\nMiddleware layers are applied in order. Early failures (rate limit, CORS) prevent deeper processing.\n\n### Components\n\n| Component | File | Purpose |\n|-----------|------|----------|\n| **Rate Limiting** | `rate-limit.ts` | IP-based request throttling |\n| **CORS** | `cors.ts` | Cross-origin resource sharing |\n| **CSRF** | `csrf.ts` | Cross-site request forgery protection |\n| **Input Validation** | `input-validation.ts` | XSS and injection prevention |\n| **Security Headers** | `security-headers.ts` | HTTP security headers |\n| **Composition** | `index.ts` | Stack orchestration |\n\n---\n\n## Installation\n\n### 1. Copy middleware files\n\nThe middleware is already in `lib/middleware/`. No npm installs needed for basic functionality.\n\n### 2. For Advanced Features (Optional)\n\nFor production DOMPurify integration:\n\n```bash\nnpm install isomorphic-dompurify\n```\n\n### 3. Configure Environment\n\nCreate `.env.local`:\n\n```bash\n# CORS: Allowed origins (comma-separated)\nALLOWED_ORIGINS=http://localhost:3000,https://example.com\n\n# CSRF: Secret key (minimum 16 characters, use strong random string)\nCSRF_SECRET_KEY=$(openssl rand -base64 32)\n\n# Rate Limiting: Requests per minute\nRATE_LIMIT_REQUESTS_PER_MIN=10\n```\n\n---\n\n## Usage\n\n### 1. Global Middleware (All Routes)\n\n**File: `middleware.ts` at project root**\n\n```typescript\nimport { createSecurityMiddlewareStack } from '@/lib/middleware';\n\nexport const middleware = createSecurityMiddlewareStack({\n  enableRateLimit: true,\n  rateLimitRequestsPerMin: 10,\n  enableCORS: true,\n  enableCSRF: true,\n  enableInputValidation: true,\n  enableSecurityHeaders: true,\n  skipPaths: ['/health', '/.well-known', '/api/public/status'],\n});\n\nexport const config = {\n  matcher: ['/((?!api/webhooks|_next/static|_next/image|favicon.ico).*)']\n};\n```\n\n### 2. Rate Limiting in API Routes\n\n```typescript\nimport { createRateLimiter } from '@/lib/middleware';\nimport { NextRequest, NextResponse } from 'next/server';\n\nexport async function POST(request: NextRequest) {\n  // Create strict limiter for auth endpoints\n  const limiter = createRateLimiter({\n    requestsPerWindow: 3, // 3 requests per minute\n    windowSizeSeconds: 60,\n  });\n\n  const clientIp = request.headers.get('x-forwarded-for') || 'unknown';\n  const result = limiter.checkLimit(clientIp);\n\n  if (!result.ok) {\n    return NextResponse.json(\n      { error: 'Too many requests' },\n      {\n        status: 429,\n        headers: { 'Retry-After': result.retryAfterSeconds.toString() }\n      }\n    );\n  }\n\n  // Handle request...\n  return NextResponse.json({ success: true });\n}\n```\n\n### 3. CSRF Protection (Form Submissions)\n\n**Backend: Generate token**\n\n```typescript\nimport { createCSRFMiddlewareFromEnv } from '@/lib/middleware';\nimport { NextResponse } from 'next/server';\n\nexport async function GET() {\n  const csrf = createCSRFMiddlewareFromEnv();\n  const token = csrf.generateToken();\n  const signed = csrf.createSignedToken(token);\n\n  const response = NextResponse.json({ token: signed });\n\n  // Set secure HTTP-only cookie\n  response.cookies.set({\n    name: '__csrf_token',\n    value: encodeURIComponent(token),\n    httpOnly: true,\n    secure: process.env.NODE_ENV === 'production',\n    sameSite: 'strict',\n    maxAge: 3600,\n    path: '/',\n  });\n\n  return response;\n}\n```\n\n**Frontend: Use token in form**\n\n```html\n<form id=\"myForm\">\n  <input type=\"hidden\" id=\"csrfToken\" />\n  <input type=\"text\" name=\"email\" />\n  <button type=\"submit\">Submit</button>\n</form>\n\n<script>\n  // Initialize form\n  async function initForm() {\n    const res = await fetch('/api/csrf-token');\n    const { token } = await res.json();\n    document.getElementById('csrfToken').value = token;\n  }\n\n  // Submit with CSRF token\n  document.getElementById('myForm').addEventListener('submit', async (e) => {\n    e.preventDefault();\n    const token = document.getElementById('csrfToken').value;\n\n    const res = await fetch('/api/submit-form', {\n      method: 'POST',\n      headers: {\n        'Content-Type': 'application/json',\n        'X-CSRF-Token': token,\n      },\n      credentials: 'include',\n      body: JSON.stringify({ email: 'user@example.com' }),\n    });\n\n    if (res.status === 403) {\n      console.error('CSRF validation failed');\n    } else {\n      console.log(await res.json());\n    }\n  });\n\n  initForm();\n</script>\n```\n\n### 4. Input Validation\n\n```typescript\nimport { InputValidator } from '@/lib/middleware';\nimport { NextRequest, NextResponse } from 'next/server';\n\nexport async function POST(request: NextRequest) {\n  const validator = new InputValidator();\n\n  const data = await request.json();\n\n  // Validate email\n  if (!validator.isValidEmail(data.email)) {\n    return NextResponse.json(\n      { error: 'Invalid email' },\n      { status: 400 }\n    );\n  }\n\n  // Sanitize strings\n  const name = validator.sanitizeString(data.name);\n  const bio = validator.sanitizeString(data.bio, true); // Allow safe HTML\n\n  // Check for injection patterns\n  if (validator.containsMaliciousPatterns(data.comment)) {\n    return NextResponse.json(\n      { error: 'Invalid input detected' },\n      { status: 400 }\n    );\n  }\n\n  // Sanitize entire object\n  const sanitized = validator.sanitizeObject(data);\n\n  return NextResponse.json({ success: true, data: sanitized });\n}\n```\n\n### 5. CORS Configuration\n\n```typescript\nimport { CORSMiddleware } from '@/lib/middleware';\nimport { NextRequest, NextResponse } from 'next/server';\n\nexport async function handler(request: NextRequest) {\n  const cors = new CORSMiddleware({\n    allowedOrigins: [\n      'https://example.com',\n      'https://app.example.com',\n      'http://localhost:3000',\n    ],\n    allowCredentials: true,\n    allowedMethods: ['GET', 'POST', 'PUT', 'DELETE', 'OPTIONS'],\n    maxAge: 86400,\n  });\n\n  // Handle preflight\n  if (request.method === 'OPTIONS') {\n    return cors.handlePreflight(request);\n  }\n\n  // Process request\n  const response = NextResponse.json({ success: true });\n  cors.addCORSHeaders(response, cors.getOrigin(request));\n\n  return response;\n}\n```\n\n---\n\n## Configuration Reference\n\n### Rate Limiting\n\n```typescript\ninterface RateLimitConfig {\n  requestsPerWindow: number;     // Default: 10\n  windowSizeSeconds: number;     // Default: 60\n  skipPaths?: string[];          // Paths to skip\n  bypassWithAuth?: boolean;      // Bypass with valid auth\n}\n```\n\n**Presets:**\n- `createRateLimiter()` — 10 req/min (default)\n- `createStrictRateLimiter()` — 3 req/min (auth endpoints)\n- `createLooseRateLimiter()` — 50 req/min (public endpoints)\n\n### CORS\n\n```typescript\ninterface CORSConfig {\n  allowedOrigins: string[];      // Required\n  allowCredentials?: boolean;    // Default: true\n  allowedMethods?: string[];     // Default: GET, POST, PUT, DELETE, PATCH, OPTIONS\n  allowedHeaders?: string[];     // Default: Content-Type, Authorization, X-CSRF-Token\n  maxAge?: number;               // Default: 86400 (24h)\n}\n```\n\n### CSRF\n\n```typescript\ninterface CSRFConfig {\n  secretKey: string;             // Min 16 chars, required\n  tokenHeader?: string;          // Default: X-CSRF-Token\n  cookieName?: string;           // Default: __csrf_token\n  tokenExpiry?: number;          // Default: 3600 (1h)\n  protectedPaths?: string[];     // Default: ['/api/']\n  protectedMethods?: string[];   // Default: [POST, PUT, DELETE, PATCH]\n}\n```\n\n### Input Validation\n\n```typescript\ninterface ValidationConfig {\n  maxBodySize?: number;          // Default: 10MB\n  maxStringLength?: number;      // Default: 10000\n  allowedTags?: string[];        // Default: safe HTML tags\n  allowedAttributes?: Record<string, string[]>;\n}\n```\n\n### Security Headers\n\n```typescript\ninterface SecurityHeadersConfig {\n  csp?: string;                  // Content-Security-Policy\n  hstsMaxAge?: number;           // Default: 31536000 (1 year)\n  hstsPreload?: boolean;         // Default: true\n  frameOptions?: string;         // Default: DENY\n  referrerPolicy?: string;       // Default: strict-no-referrer\n}\n```\n\n---\n\n## Response Headers\n\nMiddleware automatically adds security-related response headers:\n\n```\nX-RateLimit-Limit: 10\nX-RateLimit-Remaining: 7\nX-RateLimit-Reset: 1699564800\nRetry-After: 45\n\nAccess-Control-Allow-Origin: https://example.com\nAccess-Control-Allow-Methods: GET, POST, PUT, DELETE, OPTIONS\nAccess-Control-Allow-Credentials: true\n\nContent-Security-Policy: default-src 'self'; `CSRF_SECRET_KEY` to a strong random 32-character string\n- [ ] Enable HTTPS in production (HSTS header)\n- [ ] Configure rate limits based on your traffic\n- [ ] Review CSP policy for your third-party scripts\n- [ ] Set secure SameSite cookies (`strict`)\n- [ ] Enable CSRF protection on all state-changing endpoints (POST/PUT/DELETE)\n- [ ] Test CORS preflight with actual client domains\n- [ ] Monitor rate limit metrics for abuse patterns\n- [ ] Rotate CSRF secret key regularly\n- [ ] Use environment variables for all secrets\n\n---\n\n## Performance\n\n- **Rate Limiting**: In-memory store, O(1) lookup, ~1KB per tracked IP\n- **CSRF**: Token cache with auto-cleanup, minimal overhead\n- **Input Validation**: Regex-based patterns, <1ms per validation\n- **Security Headers**: Stateless, zero computational cost\n- **CORS**: Origin whitelist lookup, O(n) where n = whitelisted origins\n\n**Recommendation**: For high-traffic production, upgrade to Redis-backed rate limiting.\n\n---\n\n## Production Upgrades\n\n### Redis-Backed Rate Limiting\n\n```typescript\n// Replace MemoryRateLimitStore with Redis client\nimport { createClient } from 'redis';\n\nconst `RATE_LIMIT_REQUESTS_PER_MIN` environment variable\n- Verify X-Forwarded-For header is correct behind reverse proxy\n- Use `bypassWithAuth: true` to skip rate limits for authenticated users\n\n### CORS rejecting valid origins\n\n- Verify exact origin in `ALLOWED_ORIGINS` (protocol + domain + port)\n- Check preflight OPTIONS requests are returning 204\n- Ensure credentials header is set correctly\n\n### CSRF token validation failing\n\n- Verify `CSRF_SECRET_KEY` is set and same across app instances\n- Check cookie is being set with `httpOnly` and `secure` flags\n- Ensure token header name matches configuration\n\n---\n\n## References\n\n- [OWASP Security Headers](https://owasp.org/www-project-secure-headers/)\n- [Content Security
