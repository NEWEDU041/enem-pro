#### Option B: JSX Component Wrapper

Create a reusable component in `lib/components/AffiliateLink.tsx`:

```typescript
export interface AffiliateLinkProps {
  href: string
  affiliate: 'udemy' | 'descomplica' | 'stoodi' | 'amazon'
  text: string
  disclosure?: boolean
}

export function AffiliateLink({ 
  href, 
  affiliate, 
  text, 
  disclosure = true 
}: AffiliateLinkProps) {
  return (
    <div className="affiliate-link">
      <a 
        href={href} 
        target="_blank" 
        rel="noopener noreferrer"
        className="link-primary"
      >
        {text} →
      </a>
      {disclosure && (
        <span className="disclosure-badge">
          {getDisclosureText(affiliate)}
        </span>
      )}
    </div>
  )
}

function getDisclosureText(affiliate: string): string {
  const disclosures: Record<string, string> = {
    udemy: "Udemy affiliate link — we earn a commission",
    descomplica: "Descomplica affiliate link — no cost to you",
    stoodi: "Stoodi affiliate link — we earn a commission",
    amazon: "Amazon Associate link — we earn commission"
  }
  return disclosures[affiliate] ?? ""
}
```

## 8. Risk Mitigation & Best Practices

### 8.1 Avoid These Common Mistakes

❌ **Placing affiliate links without disclosure** → LGPD/FTC violation + loss of trust  
❌ **Promoting products you haven't tested** → Reader backlash + poor conversions  
❌ **Linking to broken/outdated courses** → Wasted traffic + negative SEO signals  
❌ **Overloading posts with affiliate links** → Kills readability & trust  
❌ **Ignoring conversion data** → Leaving money on the table  

### 8.2 Best Practices for Link Placement

1. **Limit 2–3 affiliate links per post** (max)
2. **Disclose BEFORE the link** — don't hide it in footer
3. **Use natural language** — "Explore Descomplica" not "CLICK HERE FOR COMMISSION"
4. **Link from specific, related content** — don't link "ENEM tips" to essay course
5. **Test placement** — sidebar, inline CTA, footer button — measure which converts best
6. **Exclude internal links** — only monetize external recommendations
7. **Monitor reputation** — if a partner changes commission/terms, escalate to user

### 8.3 When to Remove an Affiliate Link

- Affiliate program changes commission to <10%
- Product quality declines (course reviews drop)
- Technical issues (broken link, 404 redirect)
- Reader complaints (unsolicited email, privacy issues)
- Better alternative exists (higher commission + higher quality)
